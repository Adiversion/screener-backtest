📡 How to Get Real-Time NSE Ticker Data for ₹0 on GitHub

×

Many retail traders mistakenly believe they must pay ₹4,000/month for Zerodha Kite Connect or Thomson Reuters feeds. In the open-source GitHub quant community, there are 3 proven ways to stream sub-second / 1-second live NSE tick data without paying a single dime:

1. Shoonya / Finvasia API (GitHub: shoonya-api-py / NorenRestApi)

Finvasia offers a 100% free lifetime trading account with zero brokerage and zero API charges. Their official WebSocket gives sub-second tick-by-tick streaming for every single NSE cash and F&O contract. Simply generate your free API key and connect your Python bot via WebSocket.

2. Yahoo Finance 1-Minute Live Polling (Zero Keys / Zero Auth)

Endpoint: https://query1.finance.yahoo.com/v8/finance/chart/{SYMBOL}.NS?interval=1m. Polling this lightweight JSON endpoint every 2 to 5 seconds provides real-time Last Traded Price (LTP), bid/ask spread, and 1-minute intraday volume without any API token or authentication required.

3. Official NSE Website Live Quote Scraping (GitHub: nsepython)

Endpoint: https://www.nseindia.com/api/quote-equity?symbol={SYMBOL}. By sending standard browser headers and an active session cookie, you can directly query NSE's official live quote database refreshed every few seconds during market hours.
