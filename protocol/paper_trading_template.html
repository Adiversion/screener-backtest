📡 How to Get Real-Time NSE Ticker Data for ₹0 on GitHub

×

Many retail traders mistakenly believe they must pay ₹4,000/month for commercial API feeds. This paper trading station uses real zero-cost market feeds with zero synthetic simulation:

1. Yahoo Finance Live WebSocket Streamer (wss://streamer.finance.yahoo.com/)

The browser connects directly to Yahoo Finance's live WebSocket server. Incoming binary packets are decoded client-side using a zero-dependency Protobuf decoder (from D:\GSheetScreener\nse-momentum-engine) extracting real LTP, volume, and tick direction. When the market is open, genuine ticks stream continuously with zero cost.

2. Cloudflare Worker Keyless CORS Proxy (nse-quote.audittool-api.workers.dev)

Endpoint: https://nse-quote.audittool-api.workers.dev/?symbol={SYMBOL}.NS. Keyless Cloudflare Edge Worker that queries Yahoo Finance's underlying JSON quote cache to fetch audited Last Traded Prices (LTP) without rate limits or CORS restrictions.

3. Shoonya / Finvasia API (GitHub: Shoonya-API/NorenRestApiPy)

Finvasia offers a 100% free lifetime trading account with zero brokerage and zero API charges. Their official WebSocket gives sub-second tick-by-tick streaming for every single NSE cash equity and F&O contract.

4. Official NSE Website Live Quote Scraping (GitHub: nsepython)

Endpoint: https://www.nseindia.com/api/quote-equity?symbol={SYMBOL}. Direct exchange quote cache refreshed continuously by NSE web servers.
